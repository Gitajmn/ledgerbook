### 又踩到的两个脚本坑（已记入开发日志模板）

- **PowerShell 的 `return $list` 会把 `List<T>` 展开成定长数组** → 之后 `RemoveRange`/`Insert` 全部报"集合的大小是固定的"。正确写法是 `New-Object 'System.Collections.Generic.List[string]'` 后逐个 `[void]$list.Add(...)`。
- 按"行号插入"时，若插入点紧邻 `if (...)`，容易插进 `if` 块内部 → 必须回读确认（本次就是这样发现并手工修正的）。
### 毛刺问题的最终结论（更正我上一轮的错误判断 ✗）

- **我上一轮判断错了**：把"饼图竖向毛刺"当成了**白色分隔线**的问题 ✗，删掉了白描边 —— 但用户要的是**保留白边** ✓，而且删掉后毛刺**依旧存在** ✓ → 说明成因不是白边。
- **重新定位（放大 3~4 倍看像素）**：左右两端各有一条**竖着的小刺** ✓。真因：外壁圆弧的两端**正好落在椭圆的左右极点**（那里椭圆切线是竖直的）✓，而外壁/顶面是靠 **1px 白描边勾勒** 的 ✗ → 描边的端点在两端就被画成一**小段竖线** ✓ = 竖刺。
- **最终修法（不再靠描边勾勒）**：① 扇形与外壁**只填充**（去掉描边）② 白色分隔线改成**径向直线**（圆心 → 外沿，每个分界画一次）③ 外轮廓改成**一整条闭合椭圆**（一条曲线，两端不会有描边端点）。
- **效果**：竖刺消失 ✓，白色分隔线与外轮廓的观感**保留** ✓（放大 4 倍复核：`0.2.3.5-饼图-放大诊断.png` → `0.2.3.5-饼图-放大最终.png`）。
- **教训**：界面"糊/毛刺"这类问题，先**放大截图看像素**再动手 ✓；不要凭第一印象改（本次因误判多绕了一轮 ✗）。

## 2026-10-15　抢救两处（0.2.4 同版重出）

### 问题 1：更新完**没有**弹出更新公告

**根因（日志铁证）**：用户安装目录的日志写着
`2026-10-15 08:08:01  [信息]  首次安装（记录版本 0.2.4）→ 按约定不弹更新内容`
—— 判断依据 `配置\上次运行版本.txt` 是 **0.2.4 才引入**的，**0.2.3 的安装里根本没有这个文件**，
于是 0.2.3 → 0.2.4 的第一次启动读到空值，被一律当成"首次安装" → **不弹**。

**修法**：没有状态文件时**再看有没有账本数据**（`HasExistingData()`：数据目录里存在 >2 字节的 .jsonl，或备份目录非空）——
有账 = 老用户升级 → **按"更新"处理，弹公告**；没账 = 真·新装 → 不弹。

**实测**（三条路径都对）：

| 情形 | 日志 |
|---|---|
| 有账 + 无状态文件（用户的情形） | `没有状态文件但已有账本数据 → 视为更新（老版本升级）→ 弹更新内容` |
| 无账 + 无状态文件（真·新装） | `首次安装（没有账本数据）→ 按约定不弹更新内容` |
| 状态文件=0.2.3（日后升级） | `更新后首次打开：0.2.3 → 0.2.4 → 弹更新内容` |

### 问题 2：「查看更新内容」打开后**无法滚动**

**根因**：窗口里的卡片是 `StackPanel` —— StackPanel 会给子元素**无限高度**，
于是只读文本框被撑到**全文高度**，滚动条永远不出现（内容被窗口裁掉）。

**修法**：卡片改成 `Grid`（Auto / **\*** / Auto）：标题与底部按内容，
**正文那一行拿"剩余高度"** → 内容超出时文本框自己出滚动条。

**实测**：`--whats-new` 截图里右侧**出现垂直滚动条**（滑块约占 40%，下面还有内容），底部按钮与提示正常。
