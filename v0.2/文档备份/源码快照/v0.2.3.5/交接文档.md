## 3. 数据格式（和 v0.1 兼容，格式版本 3）

- **位置**：默认"程序所在目录"（绿色便携）；程序目录不可写时退到 `%LOCALAPPDATA%\记账本`；
  环境变量 `JIZHANG_ROOT` 或 `记账本根目录` 优先。
- **结构**：`数据\年\月\YYYY-MM-DD.jsonl`，**一行一条记录、字段带名字**（UTF-8 无 BOM）。
- **字段**：日期 / 时间 / 类型（支出·收入）/ 金额 / 分类 / 支付方式 / 短备注 / 详细备注 / 归属 / 来源（后两个为预留列）。
- **兼容**：格式版本 1 = 每天一个 TSV 7 列、2 = TSV 9 列；**老 TSV 仍可读**，改写时自动升级成 JSONL 并先备份老文件；
  认不出的行会原样保留，不会丢。
- **导出**：CSV（UTF-8 **带 BOM**，Excel 双击不乱码），支持往返（含编号列）。
- **导入**：认 CSV/TSV，按首行猜分隔符；先出"导入预览"，改动选项即时刷预览；重复行可跳过、可按编号覆盖；
  可统一改用户码 / 设备名。
- **约定**：金额统一两位小数、必须 > 0；编号 `YYYYMMDD-NNN`；改/删/导入前自动备份。

## 4. 安装体系（自研安装器，甲方案）

- **交付物**：`完整包`（约 62MB：程序 + 内置运行时 + 卸载器）/ `小包`（约 0.8MB：只有程序 + 卸载器）。
- **负载结构**（"更新只写 0.4MB"的关键）：
  - 程序负载 = **框架依赖**的 7 个文件（两种机器通用：有 .NET 用系统的，没 .NET 用包内运行时）；
  - 运行时负载 = `hostfxr.dll` + `shared\Microsoft.*\<版本>\`（**私有运行时布局**，实测 trace 会用包内运行时）；
  - 安装时：程序总是覆盖；运行时只在"系统没 .NET 8 **且** 目标目录没有同版本标记"时才解，解完写 `运行时版本.txt`。
- **安装器行为**：路径页（默认 `用户目录\Programs\记账本`，可改；记住上次位置写在 `%LOCALAPPDATA%\记账本\安装位置.txt`，
  **不依赖注册表**）→ 进度页（可取消）→ 完成页（显示版本 + 装到哪）。
  附带：结束正在运行的记账本、按"本版文件清单"清理旧版本残留（`数据/配置/导出/备份` 永不碰）、放 `卸载记账本.exe`、
  建快捷方式（开始菜单 + 可选桌面）、写 `安装信息.txt`、可选信任签名证书。
- **命令行**：`--silent --dir <路径> [--desktop] [--trust] [--no-launch] [--test-icons] [--force-runtime]`、`--shot <png> --page 0|1|2`。
- **卸载**：双击 `卸载记账本.exe`（不带参数即卸载）或 `--uninstall --silent --target <目录>`；保留 `数据/配置/导出/备份`，
  只删空目录（**绝不 `rd /s`**），清理脚本放安装目录外、纯 ASCII 正文 + 参数传中文路径。

## 7. 0.2.2 起的图表与交互地基（后续版本按这个来）

### 7.1 图表模块 `v0.2\src\LedgerBook.App\Charts.cs`

- 四种视图：`表格`（各面板里的 `Ui.DataTable`）/ `饼状图` / `柱状图` / `方格图`；统一入口 `Charts.Draw(view, data, compact)`：
  - `compact: false`（查询统计）→ 收入、支出**上下排**，图用大尺寸（饼 108 / 柱高 62 / 方格 10）；
  - `compact: true`（月度汇总）→ 收入、支出**左右平列**，图用小尺寸（饼 92 / 柱高 46 / 方格 8）。
- 数据入口统一是 `CategoryTotal` 列表；`Draw` 内部按 `Kind` 拆成收入/支出两段，**各自按本类合计算百分比**，每段带"合计金额"小标题。
- **饼图是照 `plotrix::pie3D` 移植的 2.5D**（不是真 3D）：
  - 椭圆压扁 `2θ/π = 0.333`、厚度 `depth = 14`、`explode = 0`（不分割 → 不画径向切面）；
  - 外壁只画**朝前的下半圈**（屏幕角度 0°~180°），两端落在椭圆左右极点 → **边缘竖直**；
  - 画法**两遍**：先所有外壁、再所有顶面（不存在"谁盖谁"的层次问题）；
  - 画布高度必须按几何算足（`2×半径×压扁 + 厚度 + 边距`）并 `ClipToBounds`，否则会溢出到卡片外。
- 柱状图是**竖向 3D 方块**（正面横向渐变 + 斜顶面 + 斜右侧面），用 `UniformGrid(Rows=1)` 让柱子平分宽度铺满；空分类不画。
- 方格图 10×10 = 100 格，`WaffleCounts` 用**最大余数法**保证正好填满；每格 = 1%。
- 配色 `LightPalette`/`DarkPalette` 是 **Office（Excel 默认）色系**，随主题 `Charts.UsePalette(dark)` 切换。

### 7.2 视图多选设置

- 两个**互相独立**的设置项：`Settings.StatsViews`（查询统计，键 `分类统计显示`）与 `Settings.SummaryStatsViews`（月度汇总，键 `月度汇总统计显示`）；默认分别是 `表格+饼状图` 与 `饼状图`。
- 月度那边**不提供"表格"选项**（月度页本来就固定有一张"每天一笔一行"表）；一个都不勾时查询兜底"表格"、月度兜底"饼状图"。
- 改动后调用 `QueryPage.Reload()` / `SummaryPage.RefreshStats()`；查询页用**视图签名**判断是否需要 `BuildStatsPanels()` 重建分区。
- **多选控件的回调必须实时读设置**（`var live = _settings.XXX;`），不能用建面板时的快照 —— 否则连点会丢勾（见开发日志第二十一轮）。

### 7.3 浮层与提示（都在 `MainWindow`）

- `ShowToast(message)`：底部居中圆角卡片，5 秒自动收起；
- `ShowError(message)`：**红色 ! 图标 + 红描边、不自动收**，且**普通提示不能把它顶掉**；
- `Confirm(title, body, yesText, noText)`：**应用内确认弹窗**（背景变暗、点遮罩/Esc = 取消），用嵌套消息循环实现**同步返回**，调用处写法 `if (!_window.Confirm(...)) return;`；
- 三者都**不铺全屏命中层**（或只在必要时铺）→ 不挡鼠标、不会卡死；**启动期**（还没有主窗口）仍用系统 `MessageBox`；`RecordDialog` 内的报错也仍是系统弹窗（模态小窗会盖住浮层）。

### 7.4 滚动约定（重要）

- **全应用不显示滚动条**：所有 `ScrollBarVisibility` 一律 `Hidden`（不可见、不占位，但仍可滚）；
- 为了让隐藏后**仍能滚**，`MainWindow` 静态构造里注册了**全局滚轮处理器**（`EventManager.RegisterClassHandler(typeof(ScrollViewer), UIElement.PreviewMouseWheelEvent, ...)`），对任意 `ScrollViewer` 生效；另有 `Ui.HoverScroll(content[, height])` 作为"无滚动条可滚容器"的标准写法（带 `PanningMode = VerticalOnly`，触控板/数位板可拖）；
- **给可滚内容留高度要用 `Grid`（Auto 标题 + Star 内容）**，**不要用 `StackPanel`** —— 垂直 `StackPanel` 会给子元素无限高度，里面的 `ScrollViewer` 就"以为装得下"→ 既不滚、内容又被裁掉。

### 7.5 备份占用上限

- `Settings.BackupLimitMb`（键 `备份上限MB`，**0 = 不限**，默认 200）；依据：一条记录约 137~214 字节 → 一天 20 笔约 3KB、一年原始数据 1~3MB，而备份是"每次改动留一份当天文件"；
- 超限时 `Storage.PruneBackups()` **删最旧、至少保留最新一份**，并清掉空日期目录；自动备份后自动调用；调小上限时立刻清一次；自检里有 4 项回归。

## 8. 约定与坑（照做就行，别重复踩）

1. **`.ps1` 必须 UTF-8 带 BOM**（PS 5.1 否则按 GBK 读，中文脚本直接语法错误）；`.bat` 用 GBK(936)。
   `.cs`/`.md`/`.json` 用 UTF-8 **不带** BOM（与现有文件一致）。
2. **`robocopy` 默认不递归**，复制目录树必须 `/E`。
3. 安装器/小工具是 **C# 5 语法**（`csc.exe`）：不能用 `=>` 表达式体、`$""` 插值、`?.`、`nameof`、`out var`。
   用 `dynamic` 要 `/r:Microsoft.CSharp.dll`；`ZipArchive` 要 `/r:System.IO.Compression*.dll`。
4. **本机 `%TEMP%` 对被启动的程序不可用**（会拒绝创建目录）→ 我们的安装器/证书一律不落 `%TEMP%`。
5. **本机禁止写 `HKCU\...\Uninstall`**（连测试键都被拒）→ 任何"登记卸载信息/记安装位置"都必须非致命，且改用文件记录。
6. **本开发环境的沙箱**：启动 GUI 继承限制、`Start-Process`/`ShellExecuteEx` 会挂死、`tasklist`/WMI 被拒、
   PowerShell 里跑 GUI 必须 `UseShellExecute = $false` + `WaitForExit()`（`WaitForExit` 的返回值别漏 `$null =`，
   否则会污染函数返回值）。**沙箱里的"写入被拒"不等于用户机器上被拒**（曾据此误判）。
7. **小包（不含运行时负载）必须保护已装的运行时**：随包带 `runtime-files.txt` 清单 + 兜底规则；
   否则"跳过运行时"的那次更新会把运行时当旧版本残留删掉（踩过）。
8. **运行时负载要裁语言卫星包**（只留 `zh-Hans`），否则多 204 个文件 / +10MB；裁的时候用**显式语言名单**，
   靠 `$dir.Parent.Name -match '^\d+\.\d+\.\d+$'` 判会一个都删不掉。
9. 自检**别断言"目录里文件数不变"**：安装器本来就会清掉清单外的文件（测试留下的 trace/截图也算）。
10. 应用自检**必须给全新根目录**（带时间戳），复用旧目录会误报一堆失败。
11. 本机**没有 `rc.exe`** → 给 `.NET Framework` 自编的 exe 加 Win32 版本资源要么自己写 `.res`，要么先不做
    （应用本体的版本资源由 SDK 自动带，文件属性里能看到 0.2.1.5 这种）。
12. 项目**没有 git**：历史靠 `v<版本>\源码快照\` 和 `历史版本\` 里的存档，**每次正式版必须存档**。
