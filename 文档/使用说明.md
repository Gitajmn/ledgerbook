# 记账本 · 使用说明（测试版 v0.1.0）

## 一、怎么启动

| 方式 | 做法 | 说明 |
| --- | --- | --- |
| 推荐 | 双击 `记账.bat` | 用 `pythonw` 启动，不弹黑框 |
| 调试 | 命令行执行 `python 记账.py` | 出错时能在窗口里看到堆栈信息 |
| 自测 | `python 记账.py 自测` | 在临时目录里跑 57 项检查，不碰你的账本 |

需要 Python 3.10 以上（推荐 3.12），只用标准库，不需要装任何第三方包。
第一次运行会自动建好 `数据\ 配置\ 导出\ 备份\` 四个目录和默认分类。

## 二、记一笔

打开后默认就在「记一笔」页：

1. 日期默认今天，要补记以前的账就直接改日期；
2. 选「支出 / 收入」；
3. 填金额（只填正数，正负由类型决定）；时间留空就用此刻；
4. 选分类（不合适的到「设置」页增删）、支付方式、备注；
5. 点「保存并继续」或按回车，光标自动跳回金额，可以连着记。

**没有「撤销上一笔」按钮**——记错了请到「查询统计」页，选中那一行双击改掉，或选中后删除。
程序内部也只有一套删除逻辑，不会出现两个入口打架。

## 三、查账、改账、删账

「查询统计」页：

- 快捷范围：今天 / 昨天 / 本周 / 上周 / 本月 / 上月 / 近7天 / 近30天 / 今年 / 全部；
- 也能自己填起止日期，再按类型、分类、备注关键词筛；
- **改了「类型」（收入/支出），后面的「分类」会自动回到「全部」**，并且选项只列当前类型的种类——
  避免出现「收入 + 交通」这种永远查不到东西的组合；
- **窗口窄了会自动重排**，不用你手动调：明细与分类统计从「左右并排」变成「上下排列」，
  成排的按钮、筛选条件会自动换行，窗口缩到最窄时所有内容依然完整显示（不裁不藏）；
  明细的列宽也会自动分配，保证表头始终一行放得下；
- 上面一行是「收入 / 支出 / 结余 / 笔数」合计，右边一栏是**分类统计**；
- **分类统计可以换着看**：在「设置 → 查询 → 分类统计里显示哪些视图」里**多选**
  （表格 / 饼状图 / 柱状图 / 方格图），**勾完点右边的「保存」才生效**（按钮没改动时是灰的）；
  可以只留一个、也可以四个全开——多个视图会自动把右边这块地分成相应的小格
  （2 个并排、3~4 个摆成 2×2），只留一个时图形会放大占满整块区域；
- **饼状图是 3D 的**（带厚度），**柱状图是横向 3D 的**（每条像一块有厚度的板）；
- **图里只画有权重的分类**：占比小到显示出来是 0.0% 的项不会画进图里（否则图例会被看不出权重的项挤乱），
  图下会写一行「另有 N 项占比不足 0.05%，未在图中显示」；**表格视图仍然列出全部**，数据不会少；
- 方格图是 10×10 共 100 格，**每格代表 1%**，下面会注明一共多少格有色；
- 换视图**不会重新读数据**，只是重画，所以点起来很快；
- 点表头可以按该列排序；
- 明细里**不显示编号**：编号只是程序内部用来定位记录的主键，你按「日期 / 时间 / 分类 / 金额 / 备注」认那一行就够了；
- 选中一行点「编辑选中」（或双击）改内容；改日期会自动挪到另一天的文件；
- **删掉某个种类之后**：已经记过的账**不会被改动**，但统计时它们统一算进「**其他**」——
  笔数、金额、占比都记在「其他」名下，按「其他」筛选也能查到；把种类再加回来就又归回原分类。
  明细里会写成 `其他（原 宠物）`，一眼看出统计口径，也方便你回去改成别的种类；
- 多选后「删除选中」，删除前会自动把当月文件备份到 `备份\`；
- 「导出结果 CSV」把当前查询结果导出到 `导出\`（UTF-8，Excel 直接打开不乱码）。

## 四、导入 / 导出（和 Excel 打交道）

这两件事现在都在**「设置」页的「导入 / 导出」页**里，主界面不再单独占一个标签页。

**导出**

- 第一行「**导出路径为 …**」——点这行蓝色文字就能选导出到哪个文件夹（右边还有「打开导出目录」按钮）；
- **导出范围**：「从（日期）到（日期）」，默认是**上月同日 → 今天**；点日期会弹出**万年历**，
  打开就停在当前这一天所在的月份、当天高亮，可以直接翻月份或点「今天」，选中哪天就填哪天；
- 点「导出」，文件名形如 `导出_2026-09-08_2026-10-08_153012.csv`，写到上面那个目录里；
- 「查询统计」页的「导出结果 CSV」还在，它导出的是**当前筛选结果**（按类型/分类/关键词筛过的），
  和这里的按日期范围导出是两件事。

**导入**

- 「选择文件…」支持 `.csv / .tsv / .txt`，自动识别编码（UTF-8 / GBK / UTF-16）、
  分隔符（Tab / 逗号）和列名（中英文都认）；
- 只有**一张预览表**：能导入的行和读不出来的行放在一起，用「**状态**」列区分——
  `可导入` 就是没问题，`读不出来：原因` 会写清楚哪一行哪里不对（原始内容也一并显示）；
- **冲突策略不在这里重复出现**，它只有一份设置（上面的「导入时默认的冲突策略」），
  导入区只显示当前用的是哪个，想改就去上面改；
- 「自动新增配置里没有的种类」按需要勾选；
- 点「执行导入」前会先备份受影响的月份；完成后告诉你成功多少条、跳过多少条、覆盖多少条、失败多少条；
- 「导出读不出来的行 CSV」会把失败行连同原始内容一起导出，方便你在 Excel 里改完再导一次。

三条冲突策略：**跳过重复**（默认）/ **按编号覆盖** / **全部追加**。

## 五、月度汇总

「月度汇总」页选年份、月份 → 「生成汇总」：按日小计 + 分类小计，可导出成该月目录下的
`_月度汇总.csv` 和 `_分类小计.csv`。汇总随时可以由每日文件重算，删掉也不影响数据。

## 六、设置（平时用不到的开关都在这里）

设置页顶部是「设置」标题和「恢复全部默认」，下面一条**分页标签**，一次只显示一页，不用在一大堆选项里找：

```
通用 ｜ 记一笔 ｜ 查询 ｜ 种类与支付方式 ｜ 导入 / 导出 ｜ 数据与备份 ｜ 关于
```

| 页 | 能改什么 |
| --- | --- |
| 通用 | 货币符号（默认 ¥） |
| 记一笔 | 默认类型（支出/收入）、默认支付方式、保存后是否自动清空金额与备注、是否显示「本次打开后已记」列表 |
| 查询 | 打开查询页时的默认范围（今天/本周/本月/上月/今年/全部…）、明细最多显示多少行（默认 500，0 表示不限；合计永远按全部记录算）、分类统计里显示哪些视图（表格 / 饼状图 / 柱状图 / 方格图，可多选） |
| 种类与支付方式 | 三个方框：收入种类 / 支出种类 / 支付方式。**方框里完整列出当前所有选项**（白底 + 明显边框）；**每行最左边的小横线可以按住上下拖动排序**，鼠标停上去会提示「拖动可以调整顺序」，松手自动保存；顺序就是记账时下拉框的顺序。右边的「修改」可以增删、改名。删掉某项不影响已经记过的账 |
| 导入 / 导出 | **导出**：导出路径（点路径可改）、打开导出目录、导出范围（从/到，点日期弹万年历，默认上月同日→今天）；**导入**：选文件、单张预览表（状态列标出读不出来的行）、自动新增种类；冲突策略只在上面这一份设置里 |
| 数据与备份 | 是否在改 / 删 / 导入前自动备份（默认开）；**备份路径可点选**（右侧保留「打开备份目录」）；**配置数据**可以导出成一个文件、也可以再导入回来 |
| 关于 | 程序版本、数据格式版本、设置版本、数据目录、怎么跑自检 |

顶部有「**恢复全部默认**」，只重置这些偏好，不动你的种类、支付方式和任何账目。

设计上有一条规矩：主线页面只放日常操作，平时用不到的开关一律放进设置区，避免误触。
所以以后看到新功能没出现在主界面上，先来这里找。

## 七、数据在哪、长什么样

数据是**纯文本**，可以随时用记事本或 Excel 打开、备份、同步：

```
D:\desktop\记账\
├─ 数据\2026\02\2026-02-14.tsv     ← 每天一个文件，一行一笔
│        2026-02-14.tsv 内容示例：
│        编号          时间   类型  分类  金额    支付方式  备注
│        20260214-001  09:12  支出  餐饮  18.50   微信      早餐
├─ 数据\2026\02\_月度汇总.csv       ← 衍生文件，可重建
├─ 配置\分类.json                   ← 分类清单，可自己加
├─ 配置\设置.json                   ← 货币符号、支付方式、窗口大小
├─ 导出\查询_2026-02-14_153012.csv
└─ 备份\2026-02\20260214_153012\    ← 改/删/导入前的当月快照
```

几条规矩：

- 编号 `YYYYMMDD-NNN` 前 8 位就是日期，所以文件里不再重复存日期列，一行更省空间；
- 金额永远存正数、固定两位小数；
- **编号是程序内部的定位标记**：界面上一律不显示（明细表、修改窗口、导入预览、删除确认都看不到），
  只出现在数据文件和导出的 CSV 里；导出保留它是为了让导出的文件能原样导回；
- **编号删掉后不回收、不重排**，这样导出的 CSV 才能精确对上原来的记录；
- 手工改文件时请保留「编号」列；读不出来的行不会让程序崩，但会被跳过并在状态栏/预览里提示。

## 八、安全与兜底

- 改、删、导入前，自动把受影响月份的每日文件复制到**备份目录**（默认 `备份\`，可在「设置 → 数据与备份」里点路径改），
  目录结构是 `备份\2026-02\20260214_153012\2026-02-14.tsv`；找不回来时去那里捞。旧备份可以随时手工删。
- **配置数据**也可以备份和搬迁：「设置 → 数据与备份 → 配置数据」里
  「导出配置数据」会把**设置 + 种类**打包成一个 JSON 文件（默认放到导出目录），
  换电脑、重装或想回退到从前的配置时，「导入配置数据」选这个文件即可；
  导入是两段式的——先预览（只读），确认后才覆盖，而且**覆盖前会先把现在的 设置.json / 分类.json
  备份到 `<备份目录>\配置\时间戳\`**，翻回去很容易。
- 同一份数据同时开两个窗口会互相覆盖，程序启动时就拦住了（第二个窗口会提示已在运行）。
- 所有写入都是「先写临时文件再原子替换」，写到一半断电不会把当天账本弄坏。

## 九、打包成免安装软件（换电脑也能跑）

双击 `打包exe.bat`：没装 PyInstaller 会**自动下载到工程目录里**（不装进系统 Python），
然后产出便携版。**所有新产物都只落在 `LedgerBook\` 这个文件夹里**，删掉它不影响源码：

| 文件 / 文件夹 | 是什么 |
| --- | --- |
| `LedgerBook\记账本\记账本.exe` | **软件本体**：双击即用，目标电脑**不需要装 Python** |
| `LedgerBook\记账本\记账本-命令行.exe` | 同一程序的命令行版（给脚本调用，见第十节） |
| `LedgerBook\记账本\_internal\` | 运行库等**附属文件**，不能删 |
| `LedgerBook\记账本\使用说明.md` 等 | 随身文档（使用说明、设计文档、便携版说明） |
| `LedgerBook\记账本-便携版-v0.1.0.zip` | **安装包**：整个程序文件夹压成一个 zip，拷到别的电脑解压即用 |
| `LedgerBook\打包信息.txt` | 版本、打包时间、文件校验值、怎么重新打包 |
| `LedgerBook\版本备份\v0.1.0_<时间戳>\` | **回滚用**的源码快照（含《回滚说明.txt》） |
| `LedgerBook\build\` | 打包工具和中间产物，**可以整个删掉** |

**换电脑怎么用**：把 `记账本-便携版-v0.1.0.zip`（或整个 `记账本` 文件夹）拷过去，
解压后双击里面的 `记账本.exe` 即可。首次启动会在**同一个文件夹里**自动建好
`数据\ 配置\ 导出\ 备份\`——所以账目是跟着这个文件夹走的，换电脑、重装系统时
把文件夹带走就行（也可以只带走 `数据\` + `配置\`）。别把它放在 `C:\Program Files`
这类需要管理员权限的目录，放桌面、D 盘、U 盘都可以。
想把数据放到别处（例如网盘目录），设置环境变量 `JIZHANG_ROOT` 指向目标目录即可。

**怎么回滚**：`LedgerBook\版本备份\` 里每次打包前都会留一份源码快照。
把快照里的文件覆盖回工程根目录（想整体回滚就覆盖 `ledger\`），再跑一遍
`python selftest.py` 确认，需要的话重新双击 `打包exe.bat`。快照里没有你的账目数据，
回滚源码不会动账本。

**为什么是「一个文件夹」而不是单个 exe**：单文件 exe 每次启动都要把运行库解压到系统临时目录，
一些公司电脑和安全软件禁止往临时目录写可执行文件，程序会起不来；文件夹模式启动更快也更稳。

## 十、给脚本或别的程序调用

命令行就是一套 JSON 接口，别的语言也能直接用：

```bat
python 记账.py api list
python 记账.py api info
python 记账.py api add   "{\"kind\":\"支出\",\"category\":\"餐饮\",\"amount\":\"18.50\",\"note\":\"早餐\"}"
python 记账.py api query "{\"preset\":\"本月\"}"
python 记账.py api month "{\"year\":2026,\"month\":2}"
```

Windows 的 shell 容易吃掉 JSON 里的双引号（PowerShell 尤其明显），所以脚本调用推荐这两种写法：

```bat
echo {"preset":"本月"} | python 记账.py api query --stdin
python 记账.py api add --file 参数.json
```

输出是 UTF-8 的 JSON，成功 `{"ok": true, ...}`，失败 `{"ok": false, "error": "..."}`，退出码 0/1。

打包后的软件里同样有这个接口，用**命令行版 exe**（图形版没有控制台，看不到输出）：

```bat
LedgerBook\记账本\记账本-命令行.exe api list
LedgerBook\记账本\记账本-命令行.exe api query "{\"preset\":\"本月\"}"
```

它和图形版读写的是同一个数据目录（exe 同级的 `数据\`、`配置\`）。

## 十一、常见问题

- **界面上的圆角**：所有按钮都是自绘的圆角按钮（悬停会微微变色，主操作按钮是蓝色），
  窗口本身在 Windows 11 上也是圆角；这些都不依赖任何第三方界面库。
- **双击没反应**：先确认 `python` 在 PATH 里（命令行执行 `python --version` 有输出）；
  或直接用 `python 记账.py` 看报错。
- **Excel 打开中文乱码**：本程序的 TSV/CSV 都带 UTF-8 BOM，正常不会乱码；
  如果是 Excel 另存的旧文件，导入时会自动按 GBK/UTF-16 尝试解析。
- **想加分类**：设置页直接加，或手工编辑 `配置\分类.json`；删分类不影响已有记录。
- **想换数据目录**：设置环境变量 `JIZHANG_ROOT`（或 `记账本根目录`）。
- **想确认程序改坏了没有**：跑一遍 `python 记账.py 自测`，57 项全绿就没事。
