# 记账本 LedgerBook

一个**本地优先**的个人记账本：数据全部存在自己电脑上（JSONL 明文，可随时用记事本打开），
自带三维统计图（饼图 / 柱状图 / 方格图）、导入导出（含「粘贴文本导入」）、自动备份与运行日志。

## 构建

需要 .NET 8 SDK 与 PowerShell：

```powershell
# 只编应用
dotnet build v0.2/src/LedgerBook.App/LedgerBook.App.csproj -c Release

# 跑数据层自检（96 项）
dotnet run --project v0.2/tools/LedgerBook.SelfCheck -c Release -- <自检用的空目录>

# 一条命令出安装包 + 便携包（产物在 v0.2/v<版本>/ 下）
pwsh -File v0.2/工具/打包-自研安装包.ps1

# 安装包自检：离线逻辑 + 真装真卸 + 应用数据层（一条命令跑完）
pwsh -File v0.2/工具/安装包自检-甲.ps1 -含应用自检
```

## 安装包说明（v0.2.5）

| 包 | 大小 | 用途 |
|---|---|---|
| `…-单文件-完整.exe` | 约 62 MB | 内含 .NET 运行时，任何 Win10/11 都能装（**推荐 / 更新也用它**） |
| `…-单文件-小包.exe` | 约 0.8 MB | 只含程序本体，需机器已装 .NET 8 桌面运行时 |
| `…-内置运行时.zip` | 约 62 MB | 便携版（解压双击即用） |
| `…-精简.zip` | 约 0.5 MB | 便携版（需已装 .NET 8） |

**已装旧版本怎么更新**：退出正在运行的记账本 → 跑**完整包** → 安装路径选成**和原来相同**那一个 → 完成。
程序文件被覆盖，**数据与设置（昵称、主题、字号、统计视图等）原样保留**；安装目录里已有同版本运行时不会被重写。

**v0.2.4 起新增的更新替代检查**：安装前会读本机已装版本（目标目录 → 注册表，且注册表需安装位置一致），
**同级或更新**（`.5` 测试版与同级正式版视为同级）会先询问「已安装 xxx 版本，是否继续安装？」——
选「是」= 覆盖安装（可用于主动用旧版换掉新版），选「否」= 终止安装、不改动任何文件；
**已装更旧 = 正常升级，不询问**。静默安装（`--silent`）也不询问。

## 单位（v0.2.5 起）

每笔账都能有自己的**单位**（元 / $ / € / USD / 积分 / 小时 都行 —— 单位是开放的，最多 6 个字、不能有空格换行）：

- 设置里的「货币符号」就是**默认单位**：只影响以后新记的账，不会改动已经记好的；
- **老账**（没有单位）一律按默认单位看待，显示与统计都不受影响；
- 查询统计与月度汇总的「单位」下拉：**合计、结余与图表只算当前单位**，查询统计的明细列表仍列出全部单位；
- 导出：交换文件每行带这条账自己的单位（老账补默认单位）；月度汇总按当前单位导出，文件名也带单位。

## 数据放在哪

按优先级：程序目录（可写时）→ `%LOCALAPPDATA%\记账本`（装在 `C:\Program Files` 等受保护目录时）
→ 环境变量 `JIZHANG_ROOT` / `记账本根目录`（可把账本放到网盘等任意位置）。
应用内「设置 → 通用 → 当前数据目录」随时可查。
